# Розыгрыш призов

Учебная целевая система фабрики ПО на ИИ ([ai-factory](https://github.com/ypolosov/ai-factory)):
приложение для честных розыгрышей призов - фронтенд и API. Код пишут агенты фабрики по задачам
из Jira, решения принимают люди в PR.

## Правила предметной области

- R1. Одна заявка от участника на розыгрыш.
- R2. Заявки принимаются только в период розыгрыша.
- R3. Участнику 18 лет или больше.
- R4. Победители выбираются детерминированно из зерна, хэш которого опубликован до конца приёма
  заявок: результат может пересчитать любой.
- R5. Не больше одного приза одному участнику в розыгрыше.
- R6. Приз подтверждают за 3 дня, иначе он не востребован.

## Состояние

Каркас приложения, CI и выкладка появятся следующим этапом демо. Пока в репозитории только
описание и правила для агентов ([AGENTS.md](AGENTS.md)).
