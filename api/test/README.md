# Проверки API

`npm test` запускает модульные тесты. Для интеграционных проверок DRAW-143 нужен настоящий
PostgreSQL и переменная `TEST_DATABASE_URL` со строкой подключения:

```sh
TEST_DATABASE_URL="$DRAW_TEST_DATABASE_URL" npx vitest run api/test/redraw.postgres.test.ts
```

Пользователю базы нужны права создавать схемы. Каждый тест создаёт отдельную схему и удаляет
её после выполнения; существующие таблицы не меняются. Без `TEST_DATABASE_URL` интеграционные
тесты пропускаются. Для запуска всех тестов с проверками базы:

```sh
TEST_DATABASE_URL="$DRAW_TEST_DATABASE_URL" npm test
```

Проверяются пустая база и обновление прежней схемы с победителем, повторная инициализация,
сохранение и чтение повтора через новое подключение, ошибка уникальности
`winners (draw_id, participant)` и откат всей операции повтора. Конфликт создаёт временный
триггер PostgreSQL; SQL, ограничения и транзакции выполняются без моков.
